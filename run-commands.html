☕ Espresso Tracker

Terminal commands to run the full application

1 Start MySQL Database
Make sure MySQL is running on port 3307 (as configured in application.properties).
# Check if MySQL is running
mysql -u root -p -h 127.0.0.1 -P 3307

# If MySQL is not running via Homebrew:
brew services start mysql

# Verify the database exists (it will be auto-created if not):
mysql -u root -p -h 127.0.0.1 -P 3307 -e "SHOW DATABASES;"
The database espresso_tracker will be created automatically by Hibernate/Flyway when the backend starts.
2 Start the Spring Boot Backend
From the project root directory, run this Maven command:
# Navigate to project root (if not already there)
cd /Users/nima/My\ Codes/JaveSpring/Espresso-Tracker

# Start the backend on port 9090
mvn spring-boot:run

# Wait for output showing:
Tomcat started on port 9090 (http) with context path ''
Started TrackerApplication in 1.7 seconds
The backend will be available at http://localhost:9090. API endpoints are at http://localhost:9090/api/v1/beans and http://localhost:9090/api/v1/brew-logs.
3 Start the React Frontend
Open a new terminal window and run:
# Navigate to the frontend directory
cd /Users/nima/My\ Codes/JaveSpring/Espresso-Tracker/frontend

# Install dependencies (only needed once)
npm install

# Start the Vite dev server
npm run dev

# Wait for output showing:
VITE v8.1.3  ready in 116 ms
➜  Local:   http://localhost:5173/
The frontend will be available at http://localhost:5173. The Vite dev server automatically proxies /api/* requests to the backend at localhost:9090.
4 Open the App & Verify
With both servers running, open the frontend in your browser:
# Open in default browser
open http://localhost:5173

# Or test the API directly via the proxy:
curl http://localhost:5173/api/v1/beans

# Expected response (empty array = no data yet):
{
  "content": [],
  "page": 0,
  "size": 20,
  "totalElements": 0,
  ...
}

# ┌─────────────────────────────────────────────┐
# │  Backend:  mvn spring-boot:run              │
# │  Frontend: cd frontend && npm run dev       │
# │  Browser:  http://localhost:5173            │
# └─────────────────────────────────────────────┘

Ports:
  5173  → React frontend (Vite dev server)
  9090  → Spring Boot backend
  3307  → MySQL database

Pages:
  /            → Dashboard (recent beans + top brews)
  /beans       → All beans (card grid)
  /beans/new   → Add a new bean
  /beans/:id   → Bean details + brew logs
  /brew-log/new → Log a new espresso extraction

API Endpoints (proxied via Vite):
  GET    /api/v1/beans           → List all beans
  POST   /api/v1/beans           → Create a bean
  GET    /api/v1/beans/{id}      → Get bean by ID
  PUT    /api/v1/beans/{id}      → Update a bean
  DELETE /api/v1/beans/{id}      → Delete a bean
  POST   /api/v1/brew-logs       → Log a brew
  GET    /api/v1/brew-logs/bean/{id} → Logs for a bean
